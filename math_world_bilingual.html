ګرافونه

د خطي او درجه‌دو تابعونو ګرافونه.

مثال: د x انتګرال

د توان قانون: د xⁿ انتګرال د xⁿ⁺¹ پر (n+1) برابر دی، که n ≠ −1 وي.

∫ x dx = x²/2 + C

د ۰ څخه تر ۲ پورې معین انتګرال:

∫₀² x dx = [x²/2]₀² = 2

مثال: د x² مشتق

د توان قانون: د xⁿ مشتق n·xⁿ⁻¹ دی.

d/dx (x²) = 2x

په x = 3 کې مشتق: 2 × 3 = 6.

د ماتریس ضرب

د لومړۍ ماتریس د ستنو شمېر باید د دویمې د قطارونو له شمېر سره برابر وي.

[1 2] × [5] = [1×5 + 2×6] = [17]
        [6]

دا یوازې یو ساده مثال دی؛ د بشپړ ماتریس ضرب کې هر قطار د هرې ستنې سره ضربېږي.

د تابع ګراف

د y = 2x + 1 لپاره، که x = 2 وي، نو y = 5.

د ساده معادلې حل‌کوونکی

د ax + b = c لپاره a، b او c ولیکه.

دا تعلیمي نمونه ده؛ ځوابونه د ساده خطي معادلې لپاره محاسبه کوي.
