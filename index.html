📘 انتګرال — Integration

انتګرال د مشتق معکوسه پروسه ده.

Integration is the reverse process of differentiation.

مثال / Example:

∫ x dx = x²/2 + C

📗 مشتق — Differentiation

مشتق د تابع د بدلون اندازه ښيي.

A derivative describes how a function changes.

مثال / Example:

که f(x) = x² وي، نو f′(x) = 2x

If f(x) = x², then f′(x) = 2x.

📙 ماتریسونه — Matrices

ماتریس د عددونو یو منظم جدول دی.

A matrix is a rectangular arrangement of numbers.

مثال / Example:

A = [1 2]
[3 4]
